This project presents a statistical analysis and predictive modeling workflow using R and a publicly available health insurance cost dataset containing 1,338 records and seven variables. The objective is to explore which demographic and lifestyle-related variables are associated with billed insurance charges and to build a baseline model that predicts charges.

The work begins with data validation, including checks for dataset dimensions, data types, missing values, duplicate records, and categorical values. Descriptive statistics and exploratory visualizations are used to understand the distribution of insurance charges and compare charges across smoking status, age, BMI, and region. The analysis then applies a Welch two-sample t-test to test whether mean charges differ between smokers and non-smokers. Pearson correlation is used to summarize linear relationships between numeric variables.

A multiple linear regression model is developed with charges as the target and age, sex, BMI, number of children, smoking status, and region as predictors. Model performance is assessed using an 80/20 training and testing split and five-fold cross-validation. The evaluation includes mean absolute error (MAE), root mean squared error (RMSE), and R-squared. Diagnostic plots are included to inspect residual patterns and identify possible violations of linear regression assumptions.

The project includes the R script, original and cleaned dataset files, summary tables, hypothesis-test results, model evaluation outputs, visualizations, and a detailed Word report. The script uses a fixed random seed where applicable so that results are reproducible. The findings are intended for educational analysis only. Because the data are observational, the relationships should not be interpreted as proof of causation, and the model should not be used as the sole basis for real insurance pricing or personal medical decisions.
